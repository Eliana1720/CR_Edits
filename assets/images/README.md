# CR EDITS — Portfolio

Portfolio responsive hecho con HTML, CSS y JavaScript puro.

## Archivos
- `index.html` — estructura y textos.
- `styles.css` — diseño completo y responsive.
- `script.js` — menú mobile, animaciones y modal de proyectos.
- `assets/images/` — colocá acá tus imágenes.
- `assets/videos/` — colocá acá tus MP4.

## Videos esperados
Podés usar estos nombres directamente:
- `gastronomia.mp4`
- `eventos.mp4`
- `viajes.mp4`
- `gaming.mp4`
- `social.mp4`
- `youtube.mp4`

Si querés otros nombres, cambiá el atributo `data-video` de cada tarjeta en `index.html`.

## Antes de publicar
1. Cambiá `TUEMAIL@GMAIL.COM` por tu email real.
2. Cambiá el enlace de Instagram.
3. Reemplazá los placeholders por imágenes/miniaturas reales cuando las tengas.
4. Subí los MP4 a `assets/videos/`.

## Deploy
Funciona sin build. Podés subir la carpeta directamente a Netlify, Vercel, GitHub Pages o cualquier hosting estático.
