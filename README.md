# CR EDITS — Portfolio verde

Proyecto estático hecho con HTML, CSS y JavaScript.

## Abrir localmente
1. Abrí la carpeta en VS Code.
2. Instalá `Live Server` (Ritwick Dey) si no lo tenés.
3. Clic derecho sobre `index.html` → `Open with Live Server`.

## Personalizar
- Mail: buscá `TUEMAIL@EMAIL.COM` en `index.html`.
- Imágenes personales: están en `assets/images/`.
- Portfolio: reemplazá los bloques `.project-art` por imágenes o videos cuando tengas las miniaturas definitivas.
- Colores: están al principio de `styles.css` en `:root`.

## GitHub Pages
Subí todos los archivos al repositorio. En GitHub: Settings → Pages → Deploy from a branch → `main` / `/root`.
